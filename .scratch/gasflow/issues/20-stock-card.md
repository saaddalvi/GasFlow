# 20: Stock card

**What to build:** staff produce a statement for one party over a date range, to settle questions and share it. Covers user stories 76 and 77.

**Blocked by:** 14: Customer write-offs.

**Status:** ready-for-agent

- [ ] The stock card shows, per gas, dispatched, received back and holding, with an opening row and one row per month that expands into linked bills
- [ ] The range defaults to the current financial year from 1 April, with a "Full history" option
- [ ] Opening stock forms the starting position and is not shown as dispatched
- [ ] Each return line shows the bill it was allocated to, such as "against 1234"; unmatched quantities are marked
- [ ] Write-offs are shown distinctly from returns
- [ ] The card can be downloaded as CSV with the same figures
- [ ] The printed card shows the shop name and logo, with no address; until a logo is supplied, the app's cylinder mark is used
- [ ] The closing holding matches the Balance register for the end date
